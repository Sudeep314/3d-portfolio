# VEES Dimension Shift — Varun B R

A bright VEES-inspired personal resume site using white, light cyan (#6FE9FF), cyan (#00BCD4), and black outlines. The hero uses a real Three.js/WebGL scene with a beveled extruded V sculpture, layered metallic rings, orbiting geometry, floating shards, particles, and mouse-reactive camera/portal motion.

## Run locally
1. Extract the folder.
2. Open it in VS Code.
3. Start `index.html` with Live Server.

No npm install is needed. The Three.js ES module is loaded from jsDelivr, so an internet connection is required.

Files: `index.html`, `style.css`, `script.js`, `profile.jpg`.
